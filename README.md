# DELTARUNE Character Wiki

En kort och överskådlig webbplats som fungerar som en enkel wiki för karaktärerna i DELTARUNE. Sidan innehåller profilsidor för olika karaktärer, en kontaktformulärssida samt grundläggande styling och resurser.
den ända karaktär sidan som finns just nu är kris. 

- Öppna mappen i Visual Studio Code.
- Installera tillägget *Live Server* (i VS Code Extensions-panelen).
- Högerklicka på `index.html` och välj *Open with Live Server* för att köra sidan lokalt.
